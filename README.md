## 🚀 Cómo subir a GitHub Pages

1. Crea un repositorio en [github.com](https://github.com) (público)
2. Sube todos los archivos
3. Ve a **Settings → Pages**
4. En **Branch** selecciona `main` → carpeta `/ (root)`
5. Guarda — en 1-2 minutos tendrás tu link

---

## ☁️ Cómo subir a Azure Static Web Apps

1. Ve a [portal.azure.com](https://portal.azure.com)
2. Busca **Static Web Apps** → Crear
3. Conecta tu repositorio de GitHub
4. En la configuración:
   - **App location:** `/`
   - **Output location:** (dejar vacío)
5. Azure desplegará automáticamente con cada push a `main`
